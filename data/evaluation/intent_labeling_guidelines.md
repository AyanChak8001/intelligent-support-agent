# Spotify Customer Support Intent Labeling Guidelines

## ACCOUNT_ACCESS_SECURITY

Use for account access, login, password, security, hacking, account recovery,
username, and unauthorized account usage.

Examples:
- Can't log in
- Someone hacked my account
- Unknown device using my account


## SUBSCRIPTION_PLAN

Use for Premium, Student, Family, plan eligibility, upgrades, downgrades,
and subscription benefits.

Do not use if the main problem is an incorrect charge or payment failure.
Use BILLING_PAYMENT_REFUND instead.

Examples:
- Student Premium issue
- Family plan problem
- Premium benefits


## BILLING_PAYMENT_REFUND

Use for charges, payments, credit cards, billing information, refunds,
and payment failures.

Examples:
- Charged incorrectly
- Payment failed
- Need a refund


## PLAYBACK_AUDIO

Use for problems playing music, pausing, stopping, audio quality,
shuffle/repeat behavior, and sound issues.

Examples:
- Song won't play
- Music keeps pausing
- Audio quality problem


## DOWNLOADS_OFFLINE_STORAGE

Use for downloaded music, offline listening, lost downloads,
storage usage, and SD card issues.

Examples:
- Downloads disappeared
- Offline music missing
- Spotify using too much storage


## APP_TECHNICAL_COMPATIBILITY

Use for general application bugs, crashes, freezing, updates,
device compatibility, and web/desktop/mobile app problems.

Examples:
- App crashes
- Web player freezes
- iPhone compatibility problem


## CONTENT_AVAILABILITY_METADATA

Use for unavailable songs, albums, artists, missing content,
and incorrect music information.

Examples:
- Song unavailable
- Album missing
- Wrong artist information


## PLAYLIST_LIBRARY_DISCOVERY

Use for playlists, queue, saved music, library organization,
sorting, Daily Mix, Discover Weekly, and recommendation behavior.

Examples:
- Playlist problem
- Queue problem
- Recommendation algorithm issue


## FEATURE_REQUEST_PRODUCT_FEEDBACK

Use when the user requests a new feature or asks Spotify to add/change
product functionality.

Examples:
- Add a new feature
- Support a new device
- Add a new option


## COMMUNITY_INTEGRATIONS

Use for third-party services and integrations such as Sonos, Roku,
Facebook, smart speakers, and connected services.

Examples:
- Sonos connection problem
- Facebook connection issue
- Roku integration problem


## OTHER_UNCLEAR

Use when the message cannot be understood as a standalone support issue,
is only a follow-up, a thank-you message, a joke, or lacks enough context.

Examples:
- Thanks, it's fixed
- I found it
- Generic complaint without a clear issue
